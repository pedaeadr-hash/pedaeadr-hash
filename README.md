## Sobre mim

Sou Adrian Ariel, desenvolvedor com foco em **back-end com C# e ASP.NET Core**, **interfaces com React e JavaScript** e **banco de dados SQL**. Também trabalho bastante com consultas SQL e gosto de entender os dados e as regras de negócio por trás de cada funcionalidade.

Gosto de construir projetos completos, do modelo de dados e da API até a interface. Alguns projetos nasceram e foram feitos sem assistência de IA; em outros, parti de ideias próprias e usei IA como apoio para explorar, desenvolver e refinar a solução. Deixo essa diferença clara nos projetos em destaque.
